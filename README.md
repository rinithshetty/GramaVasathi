## 📱 About the App

Grama-Vasathi is a dual-sided Android app connecting 
village hosts (Grihastha) with urban guests (Atithi) 
for authentic rural farm-stay experiences in Karnataka, India.

## ✨ Key Features

### For Village Hosts
- 5-step profile setup wizard
- 20-item readiness checklist (Hygiene, Safety, Comfort)
- Live readiness score (0-100) with animated ring
- AI-powered hospitality tips via Gemini API
- Star Host badge system (Beginner → Good → Star)
- Farm experience catalogue

### For City Guests
- Searchable farm-stay discovery
- Activity filters (Cow Milking, Birdwatching, Pottery etc.)
- Full listing detail with photo gallery
- Simulated booking flow with date picker
- Cultural etiquette guide (offline)
- Post-stay review system

## 🚀 Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/rinithshetty/GramaVasathi.git
```

### 2. Add Firebase config
- Create a Firebase project at console.firebase.google.com
- Download `google-services.json`
- Place it in the `app/` folder

### 3. Add Gemini API Key
Create `local.properties` in root folder:
Get your free key at: https://aistudio.google.com/app/apikey

### 4. Enable Firebase Services
- Authentication (Email/Password + Phone)
- Firestore Database
- Firebase Storage
- Cloud Messaging

### 5. Run the app
Open in Android Studio and press ▶ Play
